`IconLabel` is now `Label` (`ui-label` hooks, `LabelProps`): its `icon` and `label` are both optional, so it draws text alone, an icon alone or an icon before text. `MetaLine` takes label entries (`{ icon, label, size, truncate }`) beside nodes and draws them as `Label`s.
