`FormatToolbar`'s block type select previews each type by default (`blockTypeLabels="preview"`): the name alone, without a glyph, drawn the way its block looks. The reference stylesheet draws the previews at the menu's own text size, headings bold and code blocks monospaced, so every option keeps the same height. `blockTypeLabels="plain"` restores the glyphs and plain names.
