Add linked numeric line charts and read-only event charts with interactive viewports, logarithmic axes, accessible coordinate details and full-resolution measurement placement. Drag and modifier gestures navigate numeric plots, with pointer cues and Reset view in the plot menu. Channel points and fixed references appear alongside movable cursors in a measurement table. Insert and delete cursors from the plot, or delete them from their readout rows. Edit a marker or cursor position in the table using caller-defined units.
