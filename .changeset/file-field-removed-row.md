`FileField` lists the committed files an edit removed in a group below the held files, titled by the new `removedFiles` provider string (`Removed files`) in the new `ui-file-field__removed-files` and `ui-file-field__removed-label` slots. The reference stylesheet draws each removed file as a chip the height of a file row, cutting a long name with an ellipsis.
