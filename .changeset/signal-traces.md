Add `SignalTraces`: stacked signal channels on their own value scales over one shared numeric time axis, with caller-supplied display samples, a dashed reference and a shaded envelope per channel, pointer, wheel and keyboard pan, zoom and reset, and two linked cursor sliders whose nearest-sample readings and time difference show in a table. The visible range and the cursors can be controlled, start again when the data window changes, and every time and value is written by the caller's formatters.
