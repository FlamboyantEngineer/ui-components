`BarChart` and `LineChart` take `formatValue`, which writes each value from its datum (series id and label, place and raw value) in names, tooltips and the table; `formatAxisValue`, which writes the value axis labels; and `renderTooltip`, which replaces the tooltip's content for the active value by pointer or keyboard. New types `ChartDatum`, `ChartTooltipContext` and `ChartFormatProps`.
