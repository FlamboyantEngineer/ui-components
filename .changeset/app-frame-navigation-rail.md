Add the application frame and the navigation rail.

- `AppFrame` (new): `topBar`, `navigation`, `startPanel`, `endPanel`, `bottomPanel` and `statusBar` regions around the main content, drawn as `banner`, `main`, named `complementary` and `contentinfo` landmarks (`labels` names the main region and the panels), with a skip link to the main content; `isEmbedded` (with `label`) draws plain containers inside a page or another frame. `AppFrameContent` fills a region from anywhere below the frame. Hooks: `ui-app-frame`, `__skip-link`, `__top-bar`, `__navigation`, `__start-panel`, `__main`, `__bottom-panel`, `__end-panel`, `__status-bar`, `data-embedded`.
- `AppFrameBand` (new): a named group with `leading`, `status`, tools (children) in a `ToolbarRow` that scrolls (`toolsLabel`) and `actions` (`actionsLabel`); `AppFrameBandContent` fills a part of the band from anywhere below the frame. Hooks: `ui-app-frame-band`, `__leading`, `__status`, `__tools`, `__actions`.
- `NavigationRail` (new): a `navigation` landmark with `header`, `footer` and a collapse button (`isCollapsed`, `defaultCollapsed`, `onCollapsedChange`), an optional resize handle (`isResizable`, `width`, `defaultWidth`, `onWidthChange`, `minWidth`, `maxWidth`), `persistKey` for both, and arrow-key focus movement. `NavigationRailSection` (titled list), `NavigationRailItem` (link with `icon`, `count`, `countLabel`, `isCurrent`, `onPress`; icon tile with a tooltip or initials while collapsed) and `NavigationRailGroup` (disclosure, `isExpanded`, `defaultExpanded`, `onExpandedChange`; marks and opens itself while it holds the current page). Hooks: `ui-navigation-rail` and its slots, `data-collapsed`, `data-resizable`, `data-resizing`, `data-current`, `--ui-navigation-rail-width`.
- `ProjectionProvider`: `slots` scopes a provider to the slots it owns, passing the others to the enclosing provider. `useProjectedContent(slot)` (new) reads a slot's content, `undefined` while it has none. A declaration whose children are `false` or an empty string now counts as empty, so the outlet shows its fallback.
- Provider strings: `skipToMainContent`, `appFramePanel`, `tools`, `actions`, `toggleNavigation` and `resizeNavigation`.
