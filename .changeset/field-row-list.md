Add `FieldRowList`, an ordered list of rows of caller-drawn fields (such as a select and the numeric field it chooses) with caller-applied add and remove, `minRows` and `maxRows` bounds, focus after each edit and a disabled state that disables every field through its native fieldset while keeping values visible. Adds the provider strings `fieldRows`, `fieldRowLabel`, `removeFieldRow`, `addFieldRow` and `noFieldRows`.
