Add `chipPlacement` to multiple `SelectField`s. `inside` draws the chips before the select in a new `ui-select-field__chip-frame`, which the reference sheet frames as the field's box, like a token field. The root publishes `data-chip-placement`. `FilterBar` and `ConditionBuilder` choice values now use chips inside, matching their people values.
