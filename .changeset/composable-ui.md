Compose assistant threads with Message Scroller, Message, Bubble, Input Group and the plain prompt submission hook. The scroller can follow a streaming reply after anchoring its prompt.

Compose dialogs, tabs, overlays, selection fields and display components with named parts. Dialog dismisses on outside press by default. Alert Dialog keeps confirmation open on outside press. Button's destructive variant is named `destructive` and omitted variants use secondary emphasis.
