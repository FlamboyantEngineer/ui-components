The `react` and `react-dom` peer minimum is now 19.2.0, the version the rich text editor's optional `react-reconciler` 0.33 peer needs, so a host on the minimum can add the rich-text peers without a resolution error. Hosts on React 19.0 or 19.1 must upgrade.
