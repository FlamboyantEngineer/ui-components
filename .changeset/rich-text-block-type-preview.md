`FormatToolbar` takes `blockTypeLabels`: `plain` (the default) keeps the glyph and name in the block type select, `preview` draws each type's name in a `ui-format-toolbar__block-preview` slot carrying `data-block`, so host styles can show headings and code blocks the way they look. Options keep their names, selected state and keyboard navigation, and the trigger names the current type in plain text.
