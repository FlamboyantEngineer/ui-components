Add rendered content for chats: code blocks, sources and citations, and streaming Markdown.

- `CodeBlock` (new): a block of code headed by its `title` or `language`, with a Copy button and an optional Apply action (`onApply`, `applyLabel`). The code scrolls sideways and joins the tab order while it overflows; `tokenize` highlights it with the same tokenizers as `CodeEditor`; `variant="terminal"` marks command lines after a `prompt` (`$` by default) and copies only the commands. `createCodeBlockOverride` draws a `Markdown` document's code blocks through it (`tokenizers` by fence language, a `console` fence as a terminal). Hooks: `ui-code-block` with `__header`, `__title`, `__actions`, `__apply`, `__copy`, `__code`, `__token`, `__line`, `__prompt`, `data-variant`, `data-language`, `data-token`, `data-kind`, `data-overflowing`. Strings: `codeBlockTitle`, `codeBlockCopy`, `codeBlockCopyCommands`, `codeBlockCopyOutput`, `codeBlockApply`.
- `ChatSources` and `ChatCitation` (new): a numbered list of sources labelled by its count (title link, site, snippet), and inline `[n]` markers that link to their source and preview it in a `HoverCard` on hover, keyboard focus and long press (a source without a URL opens its card on press). `createCitationOverride(sources)` turns the `[n]` markers of a `Markdown` answer into citations. Hooks: `ui-chat-sources` with `__label`, `__list`, `__item`, `__title`, `__site`, `__snippet`; `ui-chat-citation` with `__marker`, `__card`, `__title`, `__site`, `__snippet`. Strings: `chatSourcesLabel`, `chatCitationLabel`.
- `Markdown`: `isStreaming` renders a source that is still arriving: an unclosed fence shows as code, open emphasis, code spans and links close or show as their text, and a partial table row, fence line or block marker waits, so no raw markers flash. Finished blocks keep their elements, so each chunk renders only the block it changed (also without streaming, for an unchanged source and `renderNode`). New state hook `data-streaming`.
