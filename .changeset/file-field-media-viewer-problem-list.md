Add `FileField`, `MediaViewer` and `ProblemList`, and extend `FileUpload`, `Modal`, `Form` and the field base for them.

- `FileField` (new): a field whose value is a list of stored files (`FileFieldItem`: `id`, `name`, `size`, `type`, `previewUrl`, `downloadUrl`), built on `Field` and `FileUpload`. `onSelect` hands accepted files to the owner, `uploads` and `onUploadRemove` list the owner's uploads (a running one makes the field pending), `allowsMultiple` (one file by default), `variant`, `acceptedFileTypes`, `maxSize`, `maxFiles` (value and uploads together), `renderFileActions`, `renderFilePreview` and `name` (hidden inputs of the file ids). Held files get a download link; while dirty, added files are marked and removed ones can be restored. Hooks: `ui-file-field`, `__upload`, `__download`, `__removed`.
- `MediaViewer` (new): a lightbox on `Modal` over `items` (`MediaViewerItem`: `id`, `src`, `name`, `type`, `alt`, `caption`, `thumbnailUrl`, `downloadUrl`) with `selectedKey`/`defaultSelectedKey`/`onSelectionChange`, open state props and `renderItem` for files that are not images (such as a `PdfViewer`). Previous and next buttons, a thumbnail strip, arrow keys, `ZoomControl` with `+`/`-`, quarter turns, scrolling to pan and a Download link. Hooks: `ui-media-viewer` and its `__stage`, `__previous`, `__next`, `__viewport`, `__canvas`, `__image`, `__content`, `__fallback`, `__fallback-icon`, `__counter`, `__zoom`, `__rotate`, `__download`, `__thumbnails`, `__thumbnail`, `__thumbnail-image`, `__thumbnail-icon` slots, and `data-kind`.
- `ProblemList` (new): a validation summary with a heading, counts by severity in a live region and each problem (`ProblemListItem`: `id`, `message`, `severity`, `label`, `targetId`) as a button that focuses its field, then calls `onAction`. Inside a `Form` without `problems` it lists the problems the form's fields show and follows them. Hooks: `ui-problem-list`, `__title`, `__summary`, `__items`, `__item`, `__jump`, `__icon`, `__label`, `__message`, `data-severity`, `data-empty`.
- `FileUpload`: `renderFileActions` (`__file-actions`), `renderFilePreview` (`__file-media`), a type glyph for files without a thumbnail (`__file-icon`, from the new `FileUploadItem.type`), `FileUploadItem.change` (`data-change="added"`), `isReadOnly` (`data-readonly`), `aria-label`/`aria-labelledby`/`aria-describedby` for the command and `commandRef`. `isDisabled` now also disables the listed files' remove buttons.
- `Modal`: `onKeyDown` receives the key presses the dialog does not handle itself.
- `Form` and the field base: a field's registration now gives its label and shown issues (`getLabel`, `getIssues`) and the field scope has `onIssuesChange`. **Break:** code that implements `FieldScope.register` itself receives registrations with these two new members; code that builds a `FieldRegistration` must add them.
- Glyphs: `download`, `rotate`, `file`, `image`, `video`, `audio`. Provider strings: `addFile`, `addFiles`, `problems`, `problemCount`, `problemSeverity`, `downloadFile`, `previewUnavailable`, `thumbnails`, `mediaStage`.
