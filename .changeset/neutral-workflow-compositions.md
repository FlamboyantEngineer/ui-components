Provide copyable host compositions for item headers, identities, people, metrics, locations, history, page regions and response actions using generic controls and the reference stylesheet. Hosts own workflow policy and signing sessions; Modal supplies asynchronous action errors, pending behavior and focus management.

ActionRow accepts caller-ordered actions with required ids and labels. ToolbarRow is a dedicated family for wrapping or scrolling tool groups; Tabs and PdfViewer share its generic scrolling primitives. Scrollable ActionRow lead content preserves intrinsic labels beside bounded actions, and ToolbarRow paging buttons can be omitted independently of edge fades. Counted filters and selection bars compose generic controls with host state.

Remove strings used only by removed workflow APIs from the library localization contract.
