Add the `TagGroup` and `Tag` components (React Aria tag group with sizes, tones, empty state, selection and removal by button or keyboard). `BooleanField` gains the `dropdown` variant, which draws the select field's control, and the `toggle-button` variant, a React Aria toggle button that keeps the width of its widest name through the new `--ui-boolean-field-caption-width` property. The `useWidestTextWidth` measurement hook is now exported from the utilities.
