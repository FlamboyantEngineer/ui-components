ConstraintEditor takes `size`, on the shared control scale, which every control takes and its Unset buttons the size below; the root publishes `data-size`. SnippetField's Preview, Apply and Cancel buttons follow the field's size, and `toInnerControlSize` is exported beside `Field`. The new components' labs show each control size and their corner cases.
