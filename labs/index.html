Labs

Foundations

Setup

  • Control Sizes — Every single-line control at each size, with short and long content and inside large type: a control takes the height of its size, never of its content or the type around it.
  • Focus Scope — Regions that keep Tab inside, focus an element on mount, return focus on unmount and move focus with the arrow keys.
  • Languages — Switches the built-in text of a page of components between the shipped language files on the fly.
  • Portal — Overlay containers and the stacking order of overlay layers.
  • Projection — Content declared in one place and rendered at a named outlet elsewhere.
  • Provider — Built-in glyphs and strings, each shown with its default and a replacement from UiProvider.
  • Text Match — Query terms highlighted inside text labels, by substring or by word.
  • Unsaved Changes Guard — Protects unsaved edits: Save, Discard or Stay before a tab switch, a link or closing the page.
  • Visually Hidden — Content only assistive technology perceives: names for icon-only controls, context for short values and a skip link that shows on focus.

Layout

  • Layout — Page, stack, cluster, grid, toolbar row and wrapper primitives that publish layout hooks for the stylesheet.
  • Overflow List — One row that keeps the items that fit and collapses the rest into an indicator.
  • Scroll Region — A framed scroll viewport with overlay scrollbars, a marker overview and a scrolling strip.
  • Separator — Horizontal, vertical, labelled and decorative rules between groups of content, in three line styles.
  • Split View — Fixed and resizable two-pane splits with a keyboard and pointer window splitter.

Primitives

Display

  • Attribution — Who did something and when, as one sentence with a live time and the person's name.
  • Badge — Compact values and counts in every variant, tone and size.
  • Card — Framed containers with a titled header, body and footer.
  • Color Swatch — A colour shown on its own, named by its colour, in five sizes.
  • Description List — Read-only label and value pairs in inline or stacked layouts, in one or two columns.
  • Icon — Every built-in glyph at every size, labelled and decorative icons, and custom icon nodes.
  • Icon Label — Leading icon and text at every size, with truncate, grow, hidden text and custom icons.
  • Image — Responsive images with a placeholder while loading, a backup address, a fallback named by alt and a retry.
  • Inline Text Diff — A change to a text value shown inline as removed and added runs.
  • Meta Line — Inline metadata entries separated by a middot, skipping empty entries.
  • Prose Table — A static table of headings and rows that takes the typography of the text around it.
  • Record Label — Plain record labels and chips with optional metadata, previews and removal.
  • Relative Time — A timestamp read relative to now that keeps itself current and shows the absolute date in a tooltip.
  • Section Header — Section titles with supporting text and actions, standalone or naming their section.
  • Shortcut — Keyboard chords in each platform notation, with readable text and key legends.
  • Sparkline — A word-sized line or area of a series: variants, markers, gaps, a shared scale and time ticks from the scale utilities.

Rendered content

  • Barcode — Values drawn as linear barcodes: Code 128, EAN-13, UPC-A and EAN-8, quiet zones, module widths, the human-readable value, invalid values and the encoder's result.
  • Code Block — A block of code with its language, a Copy button, an optional Apply action and a terminal variant.
  • HTML Markup — Renders sanitized HTML as React elements, with links through the provider and element overrides.
  • Markdown — Renders Markdown with tables, task lists, code and links through the library's readers.
  • QR Code — Text drawn as a QR code: error correction levels, quiet zones, module sizes, dense and too-long texts, and the encoder's symbol.
  • SVG Markup — SVG markup strings rendered as React elements, alone and inside Icon.

People

  • Avatar — Person and group identities with pictures, initials, optional presence, actions, name tooltips and person cards.
  • Avatar Group — Overlapping stacks, spaced presence strips and decorative dots with cards, status and overflow.
  • User Card — A person's identity card with status, details and actions.
  • User Card Trigger — Makes an avatar, a name or a row a button that opens a person's card, on press or on hover and focus.
  • User Identity — A decorative avatar, a display name and an optional secondary line.

Feedback and status

  • Banner — Inline messages with tones, actions, dismissal and announcements.
  • Empty State — Empty, loading and error notices that stand in for missing content.
  • Inline Error — Compact alerts for failed operations with optional recovery.
  • Loading Overlay — A status card, the cover that blocks a loading surface and a region that makes its content inert.
  • Progress Bar — Linear and circular progress or measured quantities, with ranges, thresholds, status and spinners.
  • Save Status — An editor's save status, announced politely, with retry after a failed save.
  • Segmented Bar — Parts of a whole as a linear track, donut ring or pie, with counts, shares and an optional legend.
  • Skeleton — Placeholders for loading content: blocks in each shape, text lines, and a loading region that keeps real content's layout until it loads.
  • Status Light — A coloured dot beside a status label: tones, sizes, presence states with default labels, a processing state and dot-only lights.
  • Toast — Transient messages in four tones, drawn in place and pushed to a live region.

Actions

  • Action Row — A row of icon-button actions described as data, with fixed verbs, order and tooltips.
  • Button — Labelled and icon-only commands, visual variants and automatic pending states for asynchronous actions.
  • Button Group — Related buttons and icon buttons in a labelled group: spaced, compact or attached, in a row or a column, and justified.
  • Copy Button — An icon button that copies a value and confirms it with a check mark and an announcement.
  • Dropdown Menu — A button or icon button that opens a menu.
  • Expand Toggle — A chevron button that expands and collapses a row, with an aligned placeholder for leaves.
  • Link — Links in running text and on their own: emphasis, underline policy, new tabs, client-side navigation and pressable links.
  • Load More — A paging control with remaining counts and a pending state.
  • Segmented Choice — Picks one of a few mutually exclusive values of a setting from a run of segments.
  • Toolbar Scroller — A row of tools that scrolls with edge fades and scroll buttons instead of squeezing.
  • Zoom Control — Zoom out, a slider over zoom levels, zoom in, the percentage and an optional reset.

Inputs

  • Checkbox — A tick box with a visible label, a mixed state and a three-state cycle.
  • Combobox — A text input completed from a filtered, sectioned or asynchronous list of suggestions.
  • Completion List — Suggestions for an editor that keeps focus: a listbox at an anchor, trigger characters such as @ and #, documentation, an empty state and a footer.
  • File Upload — Chooses or drops files, checks their type and size, and lists them with upload progress and errors.
  • Grid Size Picker — Choose rows and columns from a growing grid, by pointer or keyboard, inline or in a popover.
  • Search Field — A search or filter box with a clear button, Escape to clear and Enter to submit.
  • Switch — An on-off switch with a track, a thumb and an optional label, without a field around it.

Navigation

  • Breadcrumb — A location trail from the outermost container to the current page, with arrow-key navigation.
  • Disclosure — Collapsible sections and accordions: a titled trigger with a start or end indicator, its panel, custom headers with actions, and groups that open one or many.
  • Pagination — Previous and next buttons around page buttons, with gaps for skipped pages.
  • Path — One line of location text truncated from the start so the final label stays visible.
  • Steps — A task in ordered steps, including an all-completed state, compact layouts and returning to a reached step.
  • Tabs — Switches between peer sections of one surface, with icons, counts, links and overflow scrolling.

Overlays

  • Context Menu — Menus opened at the pointer, from the keyboard, by a long touch or through a controller.
  • Drawer — A panel sliding in from a viewport edge: positions, sizes, header and footer, dismissal options, snap points and nested drawers.
  • Hover Card — A card of extra content shown on hover and focus of its trigger: delays, placements, arrow, interactive content and controlled state.
  • Menu — Menu items, sections, selection, check items and submenus, standalone and opened from a button.
  • Menubar — A row or column of top-level items that each open a menu, with menubar keyboard and pointer behaviour.
  • Modal — Dialog presentations with footer actions, asynchronous work and confirmation, alert and prompt helpers.
  • Modal Controller — Opens, stacks, updates and closes modals imperatively through a controller and its host.
  • Popover — A dialog floating against its trigger: placements, arrow, title and close button, non-modal, custom anchor and controlled state.
  • Tooltip — Hover and focus hints for controls, in two variants and every placement.
  • Truncation Tooltip — Text that shows its full content in a tooltip only while it is cut short.

Fields

Base

  • Field — The field base: label layouts, validation, dirty state and restore, per-field undo and redo, the field menu and a decoration slot.
  • Form — A form that validates its fields on submit, with server errors, validation modes, native validation and fieldsets.

Text and numbers

  • Decimal Field — An exact decimal held as a string, with locale text, exact steps, bounds and rounding.
  • Expression Field — Authored expression and decimal text kept exactly as typed, with a host-evaluated result.
  • Masked Text Field — A text field with a fixed token mask: raw characters as the value, formatted text with stable separators in the input.
  • Math Preview — LaTeX source typeset as MathML through KaTeX, with a source field and live preview.
  • Number Field — A field for a locale-formatted number with steppers, range and step, or picked along a slider track, as one value or a range.
  • Pin Input — A fixed-length code in single-character cells, with typing, Backspace, arrows, paste and one-time-code autofill.
  • Tags Input — A free-text list field: Enter, delimiters and pasted lists add tags; duplicates, a maximum and per-tag checks refuse them.
  • Text Field — A field for a plain string on one line or several, with string rules, commit and revert.

Dates

  • Date Time Field — Dates, times, date-times and date ranges in segments and a calendar.
  • Multi Date Field — Several independent calendar dates chosen as a set.
  • Relative Date Field — A date set from presets that read relative to now.

Choice

  • Boolean Field — A field for a true, false or unset value drawn as a checkbox, a switch, two segments, a dropdown or a toggle button.
  • Cascader Field — A field for choosing one leaf of a hierarchy through adjacent panels.
  • Choice Group — Single and multiple choice fields with rich labels, descriptions, orientation and select-all.
  • Color Field — A field for a colour value with a swatch trigger and a picker.
  • Rating Field — Ratings picked with glyphs in whole or half steps, with a hover preview, custom glyphs and a read-only Rating for aggregate scores.
  • Select Field — Choose one or several values from text and icon options, groups or a searchable tree.

Rich values

  • Code Editor — Code fields and embedded editing surfaces with preset or custom syntax, JSON schema tools and diagnostic scrollbar marks.
  • File Field — A field whose value is a list of stored files, with uploads in progress, download links and changes against the committed value.
  • Rich Text Editor — Formatted text editing on ProseMirror with a toolbar, a selection toolbar, a slash menu and block handles.
  • Signature Pad — A field for a signature drawn with a pointer or typed as a name.
  • Snippet Field — A code snippet taken from a source and line range, previewed through a host loader and saved explicitly.

Assemblies

Collections

  • Drag Handle — The drag button of a row in a collection that reorders by drag and drop.
  • Facet List — Facet values with counts as checkboxes, with search, show more and selected first.
  • List Row — Native lists of link, action and read-only rows with one tab stop and arrow-key navigation.
  • Pivot Table — Records summarized by row and column fields with aggregated values, totals, expandable groups, sorting and a field chooser.
  • Table — A data table with sorting, filtering, selection, resizable and persisted columns, reordering, notices and virtualization.
  • Tag Group — A focusable set of tags in every size and tone, with removal by button or keyboard.
  • Transfer List — Move items between available and chosen lists, with filters, counts and reordering.
  • Tree — Hierarchies of rows on React Aria's Tree: expansion, selection, links, persisted state and reordering.

Records and properties

  • Change List — What changed in a record, one row per property: word diffs of text, items added to and removed from lists, and old and new values.
  • Constraint Editor — Authors a field's required flag, default, bounds, lengths and option counts, showing conflicts without repairing them.
  • Four Side Property Strip — One property row with a top, bottom, left and right value.
  • Inline Edit — A value read in place that turns into its editor on a click, Enter or F2: Enter or leaving saves, Escape cancels, with pending and failed saves.
  • Property Filter — A property panel with a search box that filters its sections and rows.
  • Property Panel — Sections, groups, cards and rows of labelled settings for one subject.
  • Property Scope — Filters property sections and rows by a query the host owns.
  • Record Header — A record's title row: kind icon, identifier with copy, an editable title, status, metadata and actions.
  • Stat Tile — A compact metric on a card: value, delta with trend and tone, a secondary line and a chart slot.
  • Transition Menu — The current state as a badge that opens the allowed next states, with reasons for unavailable ones and an optional confirmation or required comment.

Search and filtering

  • Condition Builder — Nested all and any groups of field, operator and value rules, with reordering, a depth limit and validation.
  • Display Options — A popover choosing a collection's grouping, sort and direction, visible properties and their order, and density.
  • Filter Bar — Active filters as chips with a typed editor per field, an add menu, clear all and a search slot.
  • List Filter — Counted single-selection list filters and trailing icon actions in one compact row.
  • People Picker — Choose people and groups by search, with the current user, recent people and chips.
  • Query Field — A one-line query input on the code editor: a caller grammar highlights, completes and diagnoses.
  • View Switcher — Saved views of a collection as tabs or a menu, with a modified marker and save, save as, rename, reset, delete and default view actions.

Editing tools

  • Find Bar — A find row: the find box with the match count, previous and next match, matching options, replace and replace all, and close.
  • Folder Manager — Creates, renames, deletes and reorders folders in a tree driven by data and callbacks.
  • Form Layout — A nested form layout drawn from a plain tree, and a designer that edits it.
  • Formula Bar — Active cell reference and raw content above a spreadsheet grid, with caller tokens and evaluation.
  • Mapping Table — Source columns with sample values mapped to target fields, with suggestions, required targets, duplicate warnings and a summary.
  • Permission Matrix — Roles against permissions with checkbox cells, inherited grants, group toggles, read-only roles and dirty marks.
  • Problem List — A summary of validation problems that counts them by severity and moves focus to each field.
  • Search Pane — A search pane: the find row, a replace disclosure, and the results as one-line snippets the reader steps through and chooses.
  • Step List Editor — An ordered list of numbered steps with a text field per column, added, inserted, duplicated, deleted, dragged or moved with Alt+Arrow keys, and dirty marks.

Collaboration

  • Activity Feed — A chronological feed of events grouped by day, with a filter slot, loading of older events and an empty state.
  • Approval Panel — Who must decide and where each decision stands, with the approvals needed, reminders and the reader's own decision.
  • Comment Composer — A plain-text comment box with submit and cancel, keyboard chords, pending submits and a stored draft.
  • Comment Thread — A discussion with a quoted anchor, replies, reactions, edit and delete, resolve and reopen, and collapsed long threads.
  • Decision Control — Approve or reject, or a scored vote, with an optional or required comment and an optional signature.
  • Notification Center — A bell with the unread count that opens a notification inbox grouped by day, with read, dismiss and load more.
  • Reaction Bar — Reaction chips with counts and who reacted, toggled by the reader, with an emoji picker to add one.
  • State Timeline — A vertical history of state changes: who moved it, when and why, with the current state marked.
  • Version History — Saved versions, newest first: select one to view, two to compare, restore after a confirmation, rename, and filter by name or person.

App structure

  • App Frame — The frame of an application: top bar, navigation, panels, main content and status bar as landmarks, a skip link, and a command band filled from anywhere below.
  • Command Palette — A modal search field over a filtered menu of commands, opened with a document-wide shortcut.
  • Dock Panel — A side or bottom panel with a tab strip, a collapsed launcher rail, drag-to-expand resizing, persisted state and a drawer on narrow frames.
  • Navigation Menu — Site navigation with link panels, hover intent and dismissal.
  • Navigation Rail — Side navigation with sections, links with icons, counts and the current page, groups, collapse to icons with tooltips and a persisted width.
  • Outline — A document outline that follows the reader's scroll, jumps to headings, collapses sections and numbers entries.
  • Signature Dialog — A modal that asks for the password again before an action is signed.
  • Tour — A guided sequence of steps anchored to elements: spotlight, step count, back, next, skip and finish, modal and non-modal, remembered completion.
  • Wizard — A multi-step task: the list of steps, the current step's panel, and Back, Skip, Next and Finish.

Widgets

Media and pickers

  • Carousel — Slides with previous and next buttons, dots or thumbnails, looping, keyboard support and autoplay that pauses on hover and focus.
  • Character Grid — Search and choose symbols from categories, with recently used characters kept in storage.
  • Emoji Picker — Search, browse and choose standard or custom emoji with a skin tone, inline or in a popover.
  • Media Viewer — A lightbox that pages through images and other files with zoom, rotation, thumbnails and keyboard navigation.

Charts and diagrams

  • Chart — Accessible SVG bar, line and donut charts with axes, a toggling legend, tooltips, keyboard focus on each value, a text summary and a table view.
  • Diagram Canvas — A pannable, zoomable diagram of nodes and edges with ports, selection, moving, connecting, a minimap, a palette and an outline view.
  • Relation Columns — Upstream and downstream columns that walk the relations of an item, with a trail of the chosen chain and counts.
  • Relation Matrix — Row items against column items with a mark in each related cell, coverage counts, grid keyboard navigation, cell actions and windowing on both axes.
  • State Machine View — States and transitions laid out automatically, with initial, final and current states, read only or editable.

Planning

  • Board — Columns of cards with counts and limits, lanes, collapsing, and cards and columns moved by drag and drop or Alt+Arrow keys.
  • Calendar View — Events in a month or week view: all-day bars across days, timed events on a time grid, crowded days, today and keyboard navigation between days.
  • Dashboard Grid — Tiles on a column grid that move and resize by pointer and keyboard in edit mode, push others down, and reflow onto fewer columns when narrow.
  • Timeline — A Gantt-style timeline: zoom levels, bars with progress, milestones, dependencies, a today marker, grouped rows, pointer and keyboard editing, selection and a table view.

Documents and code

  • Annotation Layer — Highlight marks anchored to content, with a margin of cards stacked beside their anchors.
  • Merge View — Three-way merge of two texts against their base: clean changes merged, conflicts resolved by take actions or by editing the result.
  • Mini App — Self-contained HTML, CSS and JavaScript tools in a sandboxed frame, with host capabilities and saved state.
  • PDF Viewer — Pages on canvas with selectable text, zoom, page navigation and find over an injected PDF engine.
  • Redline Compare — Block-level redline of two rich documents with inline word changes, moved blocks, change navigation and accept or reject.
  • Text Diff — The line diff of two texts, unified or side by side, with word changes, folded context, line widgets and change navigation.
  • Tree Compare — Two hierarchies aligned row by row: added, removed, changed and moved rows, one expansion for both sides, only differences, steps between them and a summary.

Conversations

  • Chat — A whole conversation: an assistant that streams, works with tools, asks and waits for approval; chats between people with replies, edits, reactions, receipts and unread; a header with search; and the surfaces it sits in.
  • Chat Activity — An assistant's activity in a reply: reasoning that streams and collapses, a group of steps, a plan and a live status line.
  • Chat Attachment — Message attachments: image thumbnails that open the media viewer, file chips with type glyphs and sizes, upload progress, errors with Retry, and removable composer strips.
  • Chat Controller — useChatController drives a fake streaming agent: replies, stop, retry, errors, a queue, approvals, questions and uploads, with the event log beside the conversation.
  • Chat List — A list of conversations with search, New chat, unread counts, muted state, presence, loading and empty states.
  • Chat Message Actions — A message's action bar and context menu: copy, ratings with feedback details, reply, react, edit and delete.
  • Chat Model Picker — A compact composer control that chooses the model a message goes to and, when that model takes it, its reasoning effort.
  • Chat Parts — Renders a message's typed parts: Markdown and plain text with mention and command pills, citations and code, reasoning, tool calls with approvals and renderers, questions, plans, sources, attachments, code, diffs and custom parts, with reasoning and tool calls folded into groups of steps.
  • Chat Question — An inline card in which an agent asks one or several questions, answered by choice or in the reader's own words, collapsing to a summary.
  • Chat Sources — A labelled list of the sources an answer drew on, and inline numbered citations that preview their source.
  • Chat Tool Call — An assistant's tool call as a collapsible card with its status, arguments and result, and approvals with Approve, Deny with a reason and Always allow.
  • Chat Transcript — A conversation log that follows the latest message, with streaming and error states and a jump to latest control.
  • Message Composer — A growing text area, or a rich editor with mention and command pills and code blocks, that sends on Enter, with a + menu of actions, attachments, emoji, edit mode, recall, drafts and a Stop button while a reply streams.
