Labs

Foundations

  • Description List — Read-only label and value pairs in inline or stacked layouts, in one or two columns.
  • Icon — Every built-in glyph at every size, labelled and decorative icons, and custom icon nodes.
  • Icon Label — Leading icon and text at every size, with truncate, grow, hidden text and custom icons.
  • Inline Text Diff — A change to a text value shown inline as removed and added runs.
  • Layout — Page, stack, cluster, grid, band and wrapper primitives that publish layout hooks for the stylesheet.
  • Meta Line — Inline metadata entries separated by a middot, skipping empty entries.
  • Portal — Overlay containers and the stacking order of overlay layers.
  • Projection — Content declared in one place and rendered at a named outlet elsewhere.
  • Prose Table — A static table of headings and rows that takes the typography of the text around it.
  • Provider — Built-in glyphs and strings, each shown with its default and a replacement from UiProvider.
  • Scroll Region — A framed scroll viewport with overlay scrollbars, a marker overview and a scrolling strip.
  • Section Header — Section titles with supporting text and actions, standalone or naming their section.
  • Shortcut — Keyboard chords in each platform notation, with readable text and key legends.
  • Split View — Fixed and resizable two-pane splits with a keyboard and pointer window splitter.
  • SVG Markup — SVG markup strings rendered as React elements, alone and inside Icon.
  • Text Match — Query terms highlighted inside text labels, by substring or by word.

Actions and navigation

  • Action Button — A button whose asynchronous action keeps it pending until it settles.
  • Button — Every variant, size and state of the labelled command button, with icons and content layouts.
  • Icon Button — Every variant, size and state of the icon-only command button.
